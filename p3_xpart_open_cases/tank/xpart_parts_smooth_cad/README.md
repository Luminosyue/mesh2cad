# 坦克零件 CAD 重建

原始目录：`/data/home/cuiyuehan/project/mesh2cad/p3_xpart_open_cases/tank/xpart_parts`。45 个 STL 对应 45 个 STEP；每个 STEP 均重新导入验证为一个有效实体。

## 方法与范围

- PART_006 复用原轮胎截图的 CadQuery 旋转轮廓程序，源 STL 的 SHA-256 与原轮胎一致。
- 适合轴对称的轮胎使用多方向截面拟合，再以分段样条旋转成实体；不满足误差限制时改用曲面分块。
- 复杂零件采用保持网格拓扑的简化、原始表面法向约束的三次 Bézier 曲面拟合、三角形参数域裁剪及曲面缝合。其 CAD 面是实际曲面，但仍有大量分块，不能视为已恢复机械设计特征树。
- Bézier 面共享边界；不保证所有面间 G1/G2 连续，部分位置仍可看到接痕。这些是近似重建的 CAD 实体，不是原始设计历史，也不是可直接认定为制造级的逆向结果。
- 保留每个 STL 的原始数值坐标和装配位置，未逐件居中摆放。STL 不包含物理单位；STEP 标注 mm 但保留原始数值，不擅自放大 1000 倍。

## 交付内容

每个 `PART_###/` 文件夹包含：STEP、BREP、可重建的 Python 入口、参数 JSON、复杂零件的控制网格与法向 NPZ、实际 STEP 的三角化预览 STL、STL/CAD 双视角对比 PNG、逐件误差报告。

`comparison_gallery_1.png` 至 `comparison_gallery_3.png` 汇总全部零件。每组左侧是源 STL，右侧是从交付 STEP 回读后的渲染。所有对比共享原始坐标、相机和比例。

## 验证

PART_042 的简化结果曾产生 5 个零体积双三角形片段；已移除这 10 个简化伪影面，剩余控制网格为闭合主实体。原始 STL 未修改，并对完整原始 STL 计算偏差。
PART_042 另有一个曲面在 STEP 回读时出现方向判定异常；该面与一个相邻面沿原有外边界合并填充为一块规则 B-spline 曲面，再进行回读检查。重建脚本包含对应的局部修复流程。

先检查建模结果有效且为一个实体，再导出 STEP 并重新导入，重复检查。表面误差采用双向各 6000 个固定种子表面采样点到对方三角面的最近距离；以各零件包围盒对角线归一化，不做配准。CAD 检测网格来自交付 STEP，标准化最大边长 100 下绝对三角化偏差为 0.025。采样最大值不等同于精确 Hausdorff 距离。

曲面分块验收限：平均偏差 ≤0.2%、P95 ≤0.5%、采样最大偏差 ≤2%、体积差 ≤5%。旋转拟合允许去除扫描噪声：平均 ≤0.3%、P95 ≤0.8%、采样最大 ≤2%、体积差 ≤5%。原轮胎 PART_006 按复现原模型单独保留：平均 ≤0.3%、P95 ≤1%、采样最大 ≤3%、体积差 ≤5%。这些是本次采用的拟合筛选阈值，不是制造公差。

45 件中最大的平均偏差：0.232%；最大的 P95 偏差：0.888%；最大的体积差：3.152%。

## 重新生成与编辑

已验证运行环境：Python 3.12、CadQuery 2.8.0。单件重建需要 `cadquery numpy scipy trimesh`。在本目录运行：

```bash
python PART_006/PART_006_cad.py
python PART_002/PART_002_cad.py
```

生成的新文件名为 `PART_###_rebuilt.step`，不覆盖交付 STEP。普通旋转件可修改 `parameters.json` 的 profile；原轮胎参数位于 `scripts/reference_tire.py`；曲面分块可修改控制网格、法向或 curvature_strength 后重建。大件包含较多曲面，重建与导入会更慢。

如需从原始 STL 重新执行整批拟合，还需 `vtk shapely`，并设置环境变量 `TANK_SOURCE` 为原始 STL 目录、`TANK_OUTPUT` 为新的输出目录，然后运行 `scripts/reconstruct_tank.py`。逐件重建脚本则直接使用已交付的参数与控制数据。
