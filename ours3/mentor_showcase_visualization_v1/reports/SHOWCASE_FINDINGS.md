# Mentor Showcase Findings

This is a separate SHOWCASE built only from existing EXACT9998 VAL1000 frozen inference artifacts. It is not a paper representative figure and does not claim quantitative completeness.

The main 4-case view uses the four frozen cases already selected in `paper_qualitative_visualization_v1`, with a shared GT-derived camera and no prediction-specific fitting. The main view focuses on Input, GT, A0 Surface, A1 + GT-BRep Line, and A3 + All Curves. P1-v2 is intentionally excluded while Full Train is running.

A1 is the current stable method for this showcase. The selected cases cover operation recovery, under-generation recovery, a complex program, and a Boolean-heavy limitation.

TEST1000 was not reused. Holdout958 prediction count is zero. The running P1-v2 Full Train was not modified or queried for selection.
