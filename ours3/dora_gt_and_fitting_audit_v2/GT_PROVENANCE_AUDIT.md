# GT B-Rep provenance audit

`gt_brep_curves.json` was generated by `gt_samples()` in `scripts/dora_fitted_curve_dataset_v1.py`. It loads each frozen `model.step`, maps `TopAbs_EDGE` from the loaded final STEP shape, and samples those topological edges through `BRepAdaptor_Curve`. It does not read CAD history, sketches, construction geometry, or DSL. Both source datasets use this exact path. No coordinate transform or unit scale is applied by this extraction; this audit tests agreement with the paired `model.obj` in the same frozen asset record.
